# MECHATEN — сайт

Статическая главная страница производственного предприятия MECHATEN: мобильное металлообрабатывающее оборудование, ремонт и модернизация станков.

## Структура

- `index.html` — вся страница (HTML + CSS + JS в одном файле, без сборки и зависимостей)
- `robots.txt` — правила для поисковых роботов
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Перед публикацией

1. Заполните контакты в блоке `CONTACTS` в конце `index.html` (телефон, e-mail, адрес, режим работы). На e-mail будут уходить заявки из формы.
2. После подключения домена раскомментируйте `<link rel="canonical">` в `<head>`.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
Сайт будет доступен по адресу `https://<логин>.github.io/<имя-репозитория>/`.
